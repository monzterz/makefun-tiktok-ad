A 19-second vertical ad for make.fun, made by an AI agent in one recorded session: the hook, the
story, the press pack's brand badge on every frame, and the referral end card with the entrant's
code typed in. The repository holds the program that publishes the video's address, the script
that renders the ad, and the notes the creative was decided in.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
